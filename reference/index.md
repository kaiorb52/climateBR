# Package index

## Functions

- [`download_inmet()`](download_inmet.md) : Download historical
  meteorological data from INMET
- [`build_inmet_dataset()`](build_inmet_dataset.md) : Build a
  partitioned Arrow dataset from INMET CSV files
- [`read_inmet()`](read_inmet.md) : Read INMET meteorological
  observations
- [`kriging_inmet()`](kriging_inmet.md) : Perform ordinary kriging
  interpolation of INMET observations
- [`nearest_stations()`](nearest_stations.md) : Find the nearest INMET
  stations for each municipality

## Datasets

- [`municipality`](municipality.md) : Municipality Database
- [`inmet_stations`](inmet_stations.md) : INMET rainfall monitoring
  stations
- [`floods_rs`](floods_rs.md) : Rainfall during the 2024 Rio Grande do
  Sul floods
- [`mun_stations`](mun_stations.md) : Nearest INMET Weather Stations for
  Brazilian Municipalities
- [`rain_stations`](rain_stations.md) : INMET rainfall monitoring
  stations by year
- [`mun_stations_distance`](mun_stations_distance.md) : Distance Between
  Brazilian Municipal Centroids and INMET Rainfall Stations
